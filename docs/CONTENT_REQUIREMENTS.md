# Project content requirements

For each project, audit and capture as much as evidence allows.

## Identity

Name, role, repository, summary, current generation/legacy relation, licence.

## Musical capability

Supported instrument types, note range, polyphony, velocity, expression, aftertouch, pitch bend, supported CCs.

## Connectivity

USB MIDI, BLE MIDI, DIN, RTP/AppleMIDI, Wi-Fi/UDP, serial and any return-path limitations.

## GMB

Integration state, protocol version, automatic discovery, descriptor and change notification.

## Electronics

MCU/board, expanders, drivers, sensors, power supplies, protection and important electrical constraints.

## Mechanics

Principle, axes, transmission, actuator roles, travel, homing, calibration, fabrication processes and required tools.

## Build resources

BOM, wiring, schematics, CAD, STL, STEP, DXF, drawings, assembly guides.

## Evidence/status

Compilation, automated tests, bench testing, hardware validation and known limitations must be recorded separately.

## Firmware

Build system, environments, source location and future flash artifacts.
